# Clean Your TV — GitHub Directory

A checked directory of open-source GitHub projects to clean up your TV: debloat Android TV, Google TV and Fire TV, replace ad-heavy home screens with clean launchers, and finish with ad-free media apps.

**Live page (GitHub Pages):** https://majiatools.github.io/clean-your-tv/
**Home site:** [clean-your-tv.net](https://clean-your-tv.net/) — guides, brand hubs (Sony / TCL / Xiaomi) and setup walkthroughs. This directory is the site's [/github/](https://clean-your-tv.net/github/) page.

## What's inside

- `index.html` — the directory page as served by GitHub Pages (canonical: this Pages URL)
- The domain version of this page (canonical: clean-your-tv.net/github/, relative internal links) is maintained with the main site's source and ships in the same release package; this repo hosts the GitHub Pages edition.
- `repos.json` — the underlying data: 31 projects in 6 categories (Debloat & Cleanup, Clean Launchers, Fire TV, One-Prompt & AI-Agent Setups, Ad-Free Media Apps, Tools & Screensavers), with GitHub star counts checked against the GitHub API on October 24, 2026.

Highlights: CleanYourTV, Universal Android Debloater, Free My TV, Aerial TV, Tigris, DumbTV, TV Detox, SmartTube, scrcpy.

Independent directory — not affiliated with GitHub or the listed projects. Star counts are a dated snapshot and drift daily.
