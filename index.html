FAQ

What is the best GitHub project to remove ads from an Android TV?

CleanYourTV (Gathin23/cleanyourtv) is the current default: it debloats over Wi-Fi and installs a clean Apple TV-style home in one flow. For manual control, Universal Android Debloater gives you a GUI over every package. Fire TV owners should start with DumbTV instead — Fire OS blocks some Android TV methods.

Are these tools safe? Can I undo a debloat?

The projects listed here work over ADB without root and disable rather than delete system apps, so changes can be re-enabled. That said, disabling the wrong package can still break casting, voice search or updates — follow each project's per-brand package list, and keep a factory-reset path in mind.

My TV is a Samsung or LG. Which of these work?

Most ADB tools only work on Android TV / Google TV and Fire TV. Free My TV is the exception in this directory: it covers LG webOS and Samsung Tizen home screens as well.

What does 'one-prompt setup' mean?

Several October 2026 projects (TV Detox, TV Home, TV Vibehack, DumbTV) ship as a repo plus a prompt: you open the repo in an AI coding agent such as Claude Code or Codex, and the agent runs the ADB commands for you, asking before anything destructive. You still need a computer on the same Wi-Fi as the TV.
